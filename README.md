# Syncity — лендинг

Анимированный лендинг Syncity на дизайн-системе Syncity: ночной город, окна-двойники, одно красное окно, которое отвечает.

## Запуск

Сборки нет: статические HTML, CSS и JS.

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Структура

| Файл | Что внутри |
| --- | --- |
| `index.html` | Разметка и тексты всех блоков |
| `css/styles.css` | Токены дизайн-системы, день и ночь, все блоки |
| `js/main.js` | Генерация городов и вся анимация |

Библиотеки подключаются с CDN: GSAP 3.12.5 + ScrollTrigger и Lenis 1.1.13 (плавный скролл). Шрифты Inter Tight и JetBrains Mono — Google Fonts.

## Блоки и анимации

1. **Hero, ночь.** Город генерируется под размер экрана. Красное окно загорается первым, от него по городу расходится волна света. У красного окна по очереди появляются цитаты двойников. Курсор зажигает окна рядом, на телефоне — касание. Город уходит вниз с параллаксом.
2. **Лента вопросов.** Примеры вопросов к обществу бегут строкой.
3. **История, день.** Слева текст, справа липкий дом 4×5. По ходу скролла горит 0 → 2 → 11 → 17 окон, на последнем шаге появляется красное. Вопрос в чате печатается, ответы по сегментам появляются по одному.
4. **Одно окно.** Скролл влетает в красное окно, оно заливает экран, внутри цитата двойника на казахском с переводом.
5. **Квартал, ночь.** Шесть домов-городов вырастают из земли. Переключатель вопросов перезажигает окна: доля «за» видна горящими окнами.
6. **Два дома, день.** Живые люди и двойники загораются парами, счётчик доходит до 75%, одно расхождение обводится красным.
7. **Скорость.** Полоса агентства ползёт неделями, а 15 окон Syncity загораются за секунду.
8. **Для кого, цена, вопросы.** Мини-дома загораются при наведении.
9. **Финал, ночь.** Город загорается снизу. После отправки формы весь город отвечает волной от кнопки.

День и ночь переключаются сами по секциям (`data-scene`), цвета перетекают плавно через `@property`. Маленький дом в правом нижнем углу показывает прогресс страницы: 20 окон — 100%.

При `prefers-reduced-motion` анимации выключены, все состояния показаны сразу. Без JavaScript текст и формы остаются на месте.

## Что подключить перед запуском

- **Форма** (`#form` в `js/main.js`) пока только показывает сообщение. Подключите отправку в CRM или на почту.
- **Цифры и цитаты.** Данные в блоках «Квартал», «История» и цитаты двойников помечены как пример. Замените их реальными ответами, когда они будут.
